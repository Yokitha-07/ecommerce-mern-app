# 🛒 MERN E-Commerce Platform 

A full-featured e-commerce platform built using the **MERN stack (MongoDB, Express, React, Node.js)**.  
This project upgrades a basic store into a **Temu / AliExpress style marketplace** with advanced features like product variants, 3D viewing, AR try-on, promo codes, role-based admin dashboard, and PayHere payment integration.

---

## Live Demo 
- https://mern-ecommerce-app-yokitha.netlify.app/

## 🚀 Features

- Product variants (color & size)
- 3D product viewer
- AR try-on using TensorFlow BodyPix
- Promo codes and discounts
- Secure PayHere checkout
- Role-based admin dashboard
- User & order management

---

## 🧱 Tech Stack

**Frontend**
- React
- React Router
- TailwindCSS
- Model Viewer
- TensorFlow BodyPix

**Backend**
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- PayHere Payment Gateway
